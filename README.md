# Codeforces Java Solutions

This repository contains my **Java solutions** to problems from [Codeforces](https://codeforces.com/).  
Solutions are **organized by contest ID and problem letter**, written from scratch, tested, and follow a **consistent naming style** for easy navigation.

---

## 🚀 How to Run

1. Clone the repository:

    ```bash
    git clone https://github.com/Harsh6575/JavaProgramming.git
    cd JavaProgramming
    ```

2. Navigate to the CodeForces folder:
    ```bash
    cd src/Codeforces
    ```

3. Compile the Java file:

    ```bash
    javac <filename>.java
    ```

4. Run the compiled class:

    ```bash
    java <filename>
    ``` 

---

## 📂 Naming Convention

```bash
CF<ContestID><ProblemLetter>.java
```

Example:

`
CF2109A.java
`

CF → Codeforces
2109 → Contest ID
A → problem letter

## 💻 Why Java?

- Strong typing → Catches many bugs at compile time
- Readability → Easy for beginners to follow
- Standard library → Rich set of utilities for competitive programming
- Cross-platform → Runs anywhere with a JVM
